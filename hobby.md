# Идея личного проекта

## Идея

Сделать небольшой симулятор эксперимента с мемристивным биосенсором: задавать параметры измерения, получать набор условных показаний и сохранять результаты для сравнения запусков.

## Технологический стек

- Python 3
- pytest для автоматических проверок
- Git и GitHub для контроля версий и обсуждения изменений

## Чему хочу научиться

Разбить задачу на небольшие модули, писать проверяемые функции, фиксировать изменения понятными коммитами и использовать Pull Request для обсуждения кода.
