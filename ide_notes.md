# VS Code и командная строка

## Три удобства VS Code

1. Встроенная панель Source Control показывает изменённые файлы и diff до коммита.
2. Подсветка синтаксиса и диагностика помогают заметить опечатки прямо при редактировании.
3. Быстрый поиск по проекту (`Ctrl+Shift+F`) позволяет находить символы и текст сразу во многих файлах.

## Одно удобство CLI

Команду Git можно повторить точно в терминале или скрипте; например, `git log --oneline --graph --decorate --all` быстро показывает историю всех веток.
